# Navigation Native RSC Instant
Try out instant Navigation React Native in RSC's using Expo.

## Run
Once you've cloned the repository, you can install the dependencies and start the instant RSC Expo example:

    npm install
    npm run start
    npm run android
    npm run ios

Client `Scenes` with `Suspense` boundaries are shown instantly with fallbacks while child server `SceneViews` stream in.
